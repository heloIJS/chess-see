Build/runtime notes
-------------------
- Single-threaded. No SharedArrayBuffer is required or used.
- The compiled engine declares "Threads ... min 1 max 1". It is permanently
  single-threaded, so no Threads setoption is sent at runtime (sending a no-op
  Threads setoption to this Emscripten build stalls it). Hash is set to 64 MB.
- NNUE data is embedded in the WASM. No network access is performed at runtime.
